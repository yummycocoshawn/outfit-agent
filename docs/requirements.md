# 需求

## 目標
指定 Discord 頻道有人上傳穿搭照片時,本機程式辨識內容、記錄並回覆。

## 功能
- 收到照片先加 ⏳ 並回「處理中…」,再逐張排隊處理。
- 辨識:穿搭名稱、單品、顏色、風格、適合氣溫範圍。
- 寫入可持續累加的 `outfits.xlsx`(日期時間、上傳者、穿搭名稱、單品、顏色、風格、適合溫度、照片位置),照片存 `photos/`。
- 回覆本次結果、使用者本月第幾套、與近 7 天穿搭的相似提醒。
- `!週報`:近 7 天統計。`!刪除`:刪除自己最後一筆。`!說明`。
- 非穿搭照片:仍回覆並建檔,名稱欄為「不是穿搭」。

## 技術條件
Python 3.12 + uv;`claude -p` 本機處理;Discord Gateway 模式;`.env` 含 DISCORD_TOKEN、CHANNEL_ID、CLAUDE_MODEL、DATA_DIR。
