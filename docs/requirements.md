# 需求說明:本機 Discord 穿搭紀錄 Agent

## 目標
在我的電腦上執行一支程式。只要它開著,指定 Discord 頻道中有人上傳穿搭照片,它就會判斷穿搭內容、記錄,並回覆上傳者,包括這套的單品、風格、適合氣溫,以及本月第幾套、是否和近期穿搭太像。

## 功能
1. 收到照片,先加 ⏳ 並回覆「處理中…」。
2. 判斷是否為穿搭,列出單品、顏色、風格,估計適合氣溫範圍。
3. 將結果寫入可持續累加的 Excel 檔,並將照片存入資料夾。
4. 回覆這套結果、上傳者本月第幾套;若與近 7 天某套單品重疊 ≥ 60%,提醒「很像」。
5. `!週報`:近 7 天套數、最常穿的單品 Top 3、最常見風格。
6. `!刪除`:刪除自己最後一筆紀錄。`!說明`:顯示用法。
7. 多人使用:紀錄、統計、提醒都以上傳者分開。

## 記錄欄位
日期時間、上傳者、穿搭名稱、單品、顏色、風格、適合溫度、照片位置。照片檔名格式為「日期時間_穿搭簡稱」。

## 非穿搭照片
仍需回覆、建檔、存檔。穿搭名稱欄填「不是穿搭」,說明實際內容。這類紀錄不計入統計。

## 不需要
註冊登入、大型雲端服務、對外開放的網站。

## 技術條件
- Python 3.12 + uv
- 以 `claude -p` 在本機處理照片
- Discord Gateway(bot)模式,不需 ngrok
- 設定檔 `.env`:`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`(不得 commit)

## 開發順序
先完成並測試所有防護機制(暫存資料夾、工具限制、資料與指令分離、輸出驗證),再進行後續測試。

## 需要 Claude Code 協助說明與決定的項目
- 選用哪個 Discord Python 套件(目前採用 discord.py)
- `claude -p` 的呼叫方式、固定輸出格式、照片傳入方法
- 多人同時上傳時的排隊機制
- 檔名與 Excel 儲存格的清洗規則
- 各項防護的具體實作
