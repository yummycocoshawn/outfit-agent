# Discord 伺服器設定(Windows)

目標:建立自己的 Server、一個給 agent 用的頻道、一條邀請連結。

## 1. 建立 Server
1. 開啟 Discord(桌面版或 https://discord.com/app)並登入。
2. 左側欄最下方點 **+**(新增伺服器)。
3. 選 **自行創建** → **僅供我和我的朋友使用**。
4. 名稱填 `outfit-test`,按 **創建**。

## 2. 建立 agent 專用頻道並取得 CHANNEL_ID
1. 左側頻道列表,在「文字頻道」旁按 **+**。
2. 類型選 **文字**,名稱填 `outfit-agent`,按 **創建頻道**。
3. 開啟開發者模式:左下角 **使用者設定(齒輪)** → **進階** → 打開 **開發者模式**。
4. 回到頻道列表,對 `outfit-agent` **按右鍵** → **複製頻道 ID**。
5. 這串數字就是 `CHANNEL_ID`,稍後貼進 `.env`(頻道 ID 不是機密)。

## 3. 建立邀請連結(給同學測試)
1. 對 Server 名稱按右鍵 → **邀請其他人**(或對頻道按右鍵 → **邀請其他人**)。
2. 點下方的 **編輯邀請連結**,把「到期時間」改成 **7 天**,「使用次數上限」設 **5**。
3. 按 **產生新連結** → **複製**,傳給配對的同學。
4. 同學點連結加入後,就能在 `outfit-agent` 頻道上傳照片。

## 4. 互相加入
你也要用同學給你的連結加入對方的 Server,P7、P9 才能互傳照片。
